# Tariff Classification RL

**Classification douanière européenne avec un petit modèle de langage (SLM), des outils de recherche et, à terme, de l'apprentissage par renforcement.**

Ce dépôt contient le travail réalisé dans le cadre d'un projet académique d'optimisation de SLM. Le projet explore la spécialisation d'un modèle de langage de petite taille sur une tâche structurée et vérifiable : associer une description de marchandise à un code de la nomenclature combinée (NC/CN) de l'Union européenne.

## Objectif

L'objectif scientifique est d'évaluer dans quelle mesure l'apprentissage par renforcement, peut améliorer la précision et la fiabilité d'un SLM spécialisé, tout en maîtrisant le coût de calcul.
