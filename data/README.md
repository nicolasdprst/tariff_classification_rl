# Dataset d'amorçage

Ce dossier contient une première structure de dataset pour développer le pipeline :

- `train.jsonl` : 770 exemples
- `validation.jsonl` : 100 exemples
- `test.jsonl` : 150 exemples

Chaque ligne est un objet JSON autonome. Les codes sont enregistrés sous forme de huit chiffres sans espace.

## Dataset train

Ce dataset contient les exemples d'entraînement pour l'agent. 

## Dataset validation

Ce dataset sert à évaluer le modèle pendant l'entraînement.

## Dataset test

Ce dataset sert à évaluer le modèle final.
